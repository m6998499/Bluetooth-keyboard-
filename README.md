# Phone Keyboard

Turns an Android phone (Android 9+) into a Bluetooth keyboard + touchpad for a PC. No PC software needed.

## Build the APK (no Android Studio needed)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab → "Build APK" runs automatically (about 3–5 minutes).
3. Open the finished run → download **PhoneKeyboard-apk** → unzip → install `app-debug.apk` on your phone (allow "install unknown apps").

Or open this folder in Android Studio and press Run.

## Use it
1. Open the app and allow "Nearby devices".
2. Tap **Make visible**.
3. On the PC: Settings → Bluetooth & devices → Add device → Bluetooth → pick your phone.
4. Type in the text box. Use the touchpad to move the mouse.
5. Next time, open the app and tap **Connect** → pick your PC.

Keep the app open while you use it. It's built for US keyboard layout.
